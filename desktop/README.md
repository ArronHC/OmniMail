# OmniMail Desktop

OmniMail 的 Windows 桌面客户端规划，采用 Go、Wails v2、React 和 TypeScript。

当前状态：规划阶段，尚未生成应用工程或安装依赖。

Web 1.1.0 已提供桌面账号目录与受重新验证保护的凭据导入接口，属于服务端准备能力，
不代表桌面客户端已发布。下述方案及实施计划保留早期服务端代理模式的设计记录，后续客户端
实现需另行确认最终凭据使用方式。

客户端连接用户现有的 OmniMail 服务，登录后自动读取网页端已经绑定的邮箱账号。
第三方邮箱凭证继续由服务端保管和使用，桌面端通过 API 收发、同步和管理邮件。

完整的技术选型、功能边界、目录设计和分期验收见
[Windows 实施计划](docs/IMPLEMENTATION_PLAN.md)。
