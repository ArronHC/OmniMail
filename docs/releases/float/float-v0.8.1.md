### 更新摘要

- Float `0.8.1` 把全部已连接邮箱带入地址页，可直接复制或填入 Gmail、Microsoft、QQ、
  NAVER、Yandex 与 Linux DO Mail 的账号地址。
- 新增本地验证码助手：识别邮件标题和摘要中带明确语义的 4–8 位验证码，并由用户一键
  复制或填入当前网页。
- 勿扰时段补齐默认时间、独立开关和本机时间编辑。

### 新增

- OmniMail、iCloud、Gmail、Microsoft、QQ、NAVER、Yandex 与 Linux DO Mail 的邮件列表
  统一显示已识别验证码及“复制 / 填入”快捷操作。
- 多个验证码输入框且用户未明确聚焦目标时，Float 会拒绝猜测并提示先选择输入框。
- 地址页的来源选择器覆盖全部已连接来源；外部来源直接显示账号状态与地址操作。

### 改进

- 勿扰时段默认使用 `22:00–07:00`，默认关闭，可独立启用并手动修改开始和结束时间。
- 复制邮箱与验证码增加浏览器兼容回退，不需要新增扩展权限。
- 验证码操作只在明确识别到内容时渐进显示，保持窄面板邮件列表紧凑。

### 修复

- 修复部分悬浮面板环境无法通过 Clipboard API 复制地址的问题。
- 修复外部邮箱账号不能从地址页直接填入当前网页的问题。
- 修复 QQ 邮箱来源名称在英文界面中残留中文的问题。

### 安全

- 验证码只从扩展已获授权的邮件标题和摘要中在本地识别，不上传新的网页或邮件数据。
- 只有用户点击后才会复制或填入；Content Script 不读取网页原有表单值。
- 本版本不新增浏览器权限、设备令牌 Scope 或第三方邮箱凭据访问。

### 兼容性

- 需要 OmniMail Web/API `0.10.4` 或更高版本，以及 Chrome 120 或更高版本。
- 可从 Float `0.8.0` 直接覆盖升级，不需要重新授权。

### 安装与升级

- GitHub Release 提供 `omnimail-float-0.8.1.zip`；解压后可在 Chrome 开发者模式中加载。
- Chrome Web Store 条目 `fpeecjailboemocpmpcbjaghpkpcaihf` 已于 2026-08-31 发布本版本。
- 商店版需要生产 OmniMail Web/API `0.10.4` 或更高版本。

### 测试

- 已通过 TypeScript、Oxlint、生产构建、153 个测试文件共 626 项测试。
- 已通过真实 Chromium 冒烟测试，覆盖验证码复制、单输入框填入、多输入框拒绝猜测、
  全部邮箱来源显示、亮暗主题和英文界面。
