### 更新摘要

- OmniMail Web/API 升级到 `1.0.0`，成为面向个人和小团队自托管场景的首个稳定兼容基线。
- Web 与 Float 共用八类官方邮箱来源 ID 和工作区路径，避免两端来源清单或深链接静默漂移。
- 新增 Float `1.x` 兼容矩阵与契约回归，冻结账号状态、能力名称和通知深链接语义。

### 升级说明

- `1.x` 只允许向后兼容地增加可选能力；破坏既有来源、状态或深链接语义需要新的主版本。
- Web `0.10.4` 可直接升级，不新增 D1 迁移、Worker 变量、Secret 或资源绑定。
- Float `1.0.0` 需要 Web/API `1.0.0` 或更高兼容版本；生产 Web 应先于商店扩展发布。

### 安全边界

- 本版本不扩大设备令牌 Scope，不改变凭据存储、邮件正文清理或远程图片策略。
- 项目仍不是端到端加密邮箱，也不替代企业反垃圾、合规归档、灾难恢复或高可用系统。

### 测试

- 发布前运行 Node/Worker 单元测试、Web E2E、Float Chromium smoke、生产构建与 Wrangler
  dry-run。
- 生产部署继续通过 D1 迁移门禁；没有待执行迁移时不会修改数据库结构。

### 发布

- Web 版本为 `1.0.0`，通过 GitHub Tag `v1.0.0` 发布。
- OmniMail Float 使用独立 Tag `float-v1.0.0` 和 Chrome Web Store 发布流程。
