### 更新摘要

- 手机端以左侧导航抽屉替代拥挤的底部导航栏，已启用多个邮箱来源时仍保持清晰的单列结构。
- 邮件列表、详情、第三方邮箱与草稿编辑器使用完整移动端视口，减少遮挡并增加可用空间。

### 改进

- 文件夹、第三方邮箱、管理员功能和账户入口复用同一套导航内容，避免桌面与手机入口漂移。
- 抽屉支持遮罩、关闭按钮、Escape 键、焦点约束、选择后自动收起和长列表内部滚动。
- 菜单按钮采用适合触控的尺寸，并适配安全区、浅色主题、深色主题及减少动态效果设置。

### 升级说明

- Web `1.0.0` 可直接升级，无需 D1 迁移、变量、Secret、资源绑定或其他额外操作。
- 本次只发布 OmniMail Web `1.0.1`；OmniMail Float 和 Android 使用独立版本号，不受影响。

### 测试

- 通过 Node/Worker 单元测试、Web E2E、生产构建和 Wrangler dry-run。
- 覆盖 360、393、430 像素宽度、深浅主题、键盘关闭与焦点恢复，以及 iCloud、Gmail、
  Microsoft、Linux DO Mail、草稿和管理员页面的移动端回归。

### 发布

- Web 版本为 `1.0.1`，通过 GitHub Tag `v1.0.1` 发布，不包含额外下载文件。
