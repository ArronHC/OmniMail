### 更新摘要

- 邮件列表的已读与未读状态现在更容易辨认：未读发件人和主题加粗，预览文字也更醒目。
- 已读邮件恢复常规字重，未读状态点随状态消失；收藏星标继续独立表示收藏。

### 改进

- 已读邮件的发件人、主题和预览使用常规字重；未读邮件的发件人和主题使用粗体，预览使用较高字重和对比度。
- 对缺少粗体字形的中文回退字体，邮件列表允许合成粗体，保持未读状态清晰可见。
- 所有使用共享邮件列表样式的 Web 邮箱工作区同步获得这一视觉区分。

### 升级说明

- Web `1.1.3` 可直接升级。**不新增 D1 迁移、变量、Secret、资源绑定或 API 变更，无需额外操作。**
- 更新自己的 Fork，使用 `npm run build` 构建，再使用 `npm run deploy` 部署。
- Float 和 Android 使用独立版本号；本次 Float 的对应改进另见 `float-v1.0.2`。

### 测试

- 浏览器端到端测试确认未读状态点、发件人、主题和预览文字的样式差异。
- `npm run build` 通过，包括文件行数、Lint 和类型检查；完整 CI 在发布 Tag 前执行。

### 发布

- Web 版本为 `1.1.4`，通过 GitHub Tag `v1.1.4` 发布，不包含额外下载文件。
